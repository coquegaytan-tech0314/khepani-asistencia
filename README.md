# Khépani Guanajuato · Control de Asistencia

Aplicación web de asistencia y reportes diarios para el personal de
mantenimiento, jardinería, limpieza y vigilancia del Instituto Khépani Guanajuato.

- Un solo archivo: `index.html`
- Funciona en Android y iPhone desde el navegador
- Los datos se sincronizan en la nube (Firebase Firestore)

## Aviso

La clave `apiKey` de Firebase que aparece en el código **no es una contraseña**.
Es el identificador público que Google usa para las apps web de Firebase.
La protección real de los datos vive en las reglas de seguridad de Firestore.
